# Job Market Dashboard

An interactive Power BI dashboard for exploring job listings, hiring activity, job types, locations, companies, and salary information.

## Dashboard highlights

- Job type distribution across full-time, internship, freelance, and part-time roles
- Job listing counts by location and company
- Average and highest salary summary cards
- Hiring trends by posting date
- A detailed job table with title, company, location, job type, deadline, and salary fields
- Application and saved-job activity cards

## Open the report

1. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Open `Job-Market-Dashboard.pbix`.
3. Explore the visuals and interact with the charts to filter the report.

The report contains an imported Power BI model. Before making this repository public, confirm that the embedded dataset and dashboard design are approved for sharing.
